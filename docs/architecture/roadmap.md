## Phase 2 handoff

Resolve company-owned products/Media versus tenant-shared definitions; company permission multiplicity and platform/support authority; central staff/public domain topology; suspension and signed-link residual windows; language/technical capability; module entitlement/disabled cleanup; recovery maintenance window and storage-provider acceptance. No legal retention/residency/SSO/billing-provider requirements were supplied; obtain them before designing those workflows.

First repair the documented installation/CI compatibility path under a separate authorized scope, then rehearse the complete current schema on an isolated restore. Inventory all root/raw readers, SQL definer/view/trigger paths, retained FKs/bytes and event/job envelopes. Review the legacy tenant+legal-company manifest explicitly. Approval of this roadmap is not permission to implement every row automatically.
